TikTok Unfollow Check

See who you follow that does not follow you back. You use your own TikTok data file. No password, no login, and your file never leaves your device.

1. Get your data from TikTok

  1. In the TikTok app: Profile → menu (☰) → Settings and privacy → Account → Download your data.
  2. Choose Select data to download (or "custom") and tick the followers and following lists. Choose the JSON file format.
  3. Tap Request data. TikTok prepares it in the background; it can take from a few hours to a few days.
  4. When it is ready, go back to the same screen, tap Download, and save the file (a zip).

The download link expires after a few days. Use a computer or phone browser to upload the file below. You can upload the zip as it is, or the unzipped user_data.json / text files.

    Privacy

    Last updated 27 October 2026.
